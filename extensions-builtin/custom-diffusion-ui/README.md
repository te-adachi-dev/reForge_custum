# 🎨 Custom Diffusion UI

プリセット管理機能付きの使いやすいカスタムディフュージョンインターフェース

## 📋 機能概要

### ✨ 主な機能

1. **固定モデル設定**
   - prefectIllustriousXL_v3.safetensors
   - sdxl_vae.safetensors

2. **サンプラー選択**
   - DPM++ 2M
   - DPM++ 3M SDE
   - Euler a

3. **スケジューラ選択**
   - Karras
   - SGM Uniform

4. **Hires. fix**
   - ON/OFF制御
   - アップスケーラー選択:
     - 4x-UltraSharp
     - DAT x4
     - R-ESRGAN 4x+ Anime6B
     - Latent

5. **ADetailer設定（フェイスリストア）**
   - ON/OFF制御
   - 1st～4th信頼度調整

### 🎯 目玉機能

- **📚 プリセット管理システム**
  - 生成した設定をワンクリックで保存
  - 1枚目の画像をサムネイルとして表示
  - ヒストリーから過去の設定をワンクリックでロード
  - 自動的にタイムスタンプ付きで管理

## 🚀 使い方

### 1. 画像生成の基本手順

1. **プロンプト入力**
   - 「プロンプト」欄に生成したい画像の説明を入力
   - 「ネガティブプロンプト」欄に避けたい要素を入力

2. **サンプリング設定**
   - サンプラー: お好みのサンプラーを選択（推奨: DPM++ 2M）
   - スケジューラ: お好みのスケジューラを選択（推奨: Karras）
   - ステップ数: 20～30が推奨（品質重視なら40～50）
   - CFG Scale: 7.0が標準（高い値でプロンプトに忠実に）

3. **画像サイズ設定**
   - 幅・高さ: 1024×1024がSDXLの標準サイズ
   - 他の解像度も選択可能（512～2048の範囲）

4. **生成ボタンをクリック**
   - 「🎨 画像を生成」ボタンをクリック
   - 右側のギャラリーに生成結果が表示されます

### 2. Hires. fix（高解像度修正）の使い方

高品質な画像を生成したい場合:

1. **Hires. fix を有効化** にチェック
2. **アップスケール倍率**: 2.0（標準）～4.0
3. **アップスケーラー**を選択:
   - `Latent`: 速度重視（デフォルト）
   - `DAT x4`: 高品質、バランス型
   - `4x-UltraSharp`: シャープな画像
   - `R-ESRGAN 4x+ Anime6B`: アニメ絵に最適
4. **Hires ステップ数**: 10～20（元のステップ数の半分程度）
5. **Denoising strength**: 0.5～0.7（高いほど変化が大きい）

### 3. ADetailer（フェイスリストア）の使い方

顔のディテールを改善したい場合:

1. **フェイスリストアを有効化** にチェック
2. **リストア強度**: 0.5が標準（高いほど修正が強い）
3. **1st～4th 信頼度**: 0.3が標準
   - 1st: 最も重要な顔検出の閾値
   - 2nd～4th: 追加の顔検出用（複数人の場合）

### 4. プリセット保存機能 ⭐

生成した設定を保存して後で再利用できます:

1. **画像を生成**
2. **プリセット名**欄に分かりやすい名前を入力
   - 例: "ポートレート_高品質", "風景_Hires有効"
3. **💾 保存**ボタンをクリック
4. 設定が保存され、1枚目の画像がサムネイルとして登録されます

### 5. プリセットの読み込み ⭐

保存したプリセットから設定をロード:

1. **プリセットヒストリー**のギャラリーを確認
2. **読み込みたいプリセット画像をクリック**
3. 自動的に全ての設定が読み込まれます
4. そのまま「🎨 画像を生成」で同じ設定で生成可能

### 6. ヒストリーの更新

- **🔄 更新**ボタンをクリックで最新のプリセットリストに更新

## 🔧 トラブルシューティング

### プリセットが保存できない

- 画像を生成してから保存してください
- プリセット名を入力してください
- `extensions-builtin/custom-diffusion-ui/presets/` ディレクトリの書き込み権限を確認してください

### アップスケーラーが見つからない

- アップスケーラーモデルファイルが必要です:
  - `models/ESRGAN/` ディレクトリに配置してください
  - 4x-UltraSharp.pth
  - RealESRGAN_x4plus_anime_6B.pth

### 生成が遅い

- Hires. fix を無効にすると高速化します
- ステップ数を減らしてください（20～25）
- バッチサイズを1にしてください

## 📝 備考

- **固定モデル**: このUIはprefectIllustriousXL_v3用に最適化されています
- **プリセットデータ**: `presets/history.json` にJSON形式で保存されます
- **サムネイル**: 256×256にリサイズされて保存されます
- **互換性**: stable-diffusion-webui-reForge専用です
